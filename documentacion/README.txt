
SISTEMA PHARMAPLUS
Gestión de Inventario Farmacéutico
Versión 1.0

DESCRIPCIÓN:
Sistema de gestión de inventario farmacéutico con alertas automáticas para prevenir desabastecimiento de medicamentos.

Funcionalidades:
- Gestión de productos farmacéuticos
- Gestión de proveedores
- Sistema de alarmas automáticas
- Autenticación de usuarios
- API REST
- Panel de notificaciones

TECNOLOGÍAS:
Backend: Java 8+, Servlets/JSP, JDBC, BCrypt, Gson
Frontend: HTML5, CSS3, JavaScript ES6
Servidor: Apache Tomcat 9.x (puerto 8082)
Base de Datos: MariaDB/MySQL
Librerías: gson-2.10.1, mariadb-java-client-3.4.1, jbcrypt-0.4

INSTALACIÓN RÁPIDA:
1. Crear base de datos pharmaplus_db
2. Ejecutar schema.sql
3. Ejecutar data.sql
4. Configurar db.properties
5. Desplegar WAR en Tomcat
6. Acceder a http://localhost:8082/PharmaPlusWeb/
